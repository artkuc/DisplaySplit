# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive. Harassment, insults and personal attacks are not tolerated in
issues, pull requests, discussions or any other project space.

Please report unacceptable behaviour privately to the maintainer via
[GitHub private vulnerability reporting](https://github.com/artkuc/DisplaySplit/security/advisories/new). Choose any
category and say it's a conduct report. Every report is reviewed and handled confidentially. Maintainers may remove
content or block participants who don't follow this code.
